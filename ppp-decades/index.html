PPP Over the Decades

Purchasing power parity (PPP) says exchange rates should move to offset differences in inflation. Does it work? Test relative PPP on more than 50 years of real exchange-rate and consumer-price data for 14 currencies against the U.S. dollar.

1Relative PPP test: actual exchange rate vs. the PPP path

Pick a currency and a base year. Both lines start at 100 in the base year. The blue line is what the dollar value of the currency actually did. The orange line is where relative PPP says it should be if it had moved exactly with the inflation differential since the base year. The shaded gap is the miss.

S = spot rate in $ per unit of foreign currency (the U.S. is home, h; the other country is foreign, f). Ih, If = inflation rates. ef = percentage change in the value of the foreign currency. Chained over many years, the PPP path is SPPP,t = Sbase × (Ph,t / Ph,base) ÷ (Pf,t / Pf,base), where P is each country's consumer price index.

2The real exchange rate: long swings, slow pull back

The real exchange rate compares price levels in a common currency: q = S × Pf / Ph. If relative PPP held exactly, q would never move. Here it is indexed so that its average over the whole sample is 100. Above 100, the foreign currency is strong in real terms: that country's goods are expensive for Americans. Below 100, it is weak in real terms. (The gap in section 1 is exactly the change in q since the base year.)
